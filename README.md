## 🔭 Currently Building

### Aegis — Rust-Based Operating System
**Rust · x86-64 · Bare Metal · Systems Programming**

Developing a hobby operating system kernel from scratch in Rust.

**Current development areas:**
- GDT, IDT, TSS and interrupt handling.
- Physical frame allocation and virtual memory management.
- Paging, heap allocation and demand paging.
- Preemptive round-robin scheduling for kernel threads.
- Ring-3 user-mode execution and system call boundary.
- Kernel shell and hardware interaction.

🚧 **Status:** Under active development.
